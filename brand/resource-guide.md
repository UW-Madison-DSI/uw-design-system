# UW-Madison Brand Resource Guide

This directory contains official UW-Madison brand assets downloaded from [brand.wisc.edu/resources](https://brand.wisc.edu/resources/). All files are in RGB color mode at 72 PPI, intended for digital/screen use (not print).

## Logos

**Path:** `logos for digital usage/uw-institutional-logos-web-digital/`

Eight logo variants, each available as SVG, PNG, and PDF:

| Variant | File Prefix | Use Case |
|---------|------------|----------|
| W Crest (full color) | `uw-crest-color-web-digital` | Primary mark on light backgrounds |
| W Crest (1-color) | `uw-crest-1-color-web-digital` | White on dark backgrounds, monochrome contexts |
| Horizontal logo (full color) | `uw-logo-horizontal-color-web-digital` | When space is wide, brand + university name |
| Horizontal logo (1-color) | `uw-logo-horizontal-1-color-web-digital` | Monochrome horizontal |
| Horizontal logo (reverse) | `uw-logo-horizontal-color-reverse-web-digital` | White version for dark backgrounds |
| Vertical logo (full color) | `uw-logo-vertical-color-web-digital` | Stacked layout |
| Vertical logo (1-color) | `uw-logo-vertical-1-color-web-digital` | Monochrome stacked |
| Vertical logo (reverse) | `uw-logo-vertical-color-reverse-web-digital` | White stacked for dark backgrounds |

**Usage rules:** Place in upper-right corner. Clear space = width of the W Crest. Never modify colors or elements. See [brand.wisc.edu/visual-identity/logos/usage](https://brand.wisc.edu/visual-identity/logos/usage/).

## File Naming Conventions

Most assets follow this pattern:
```
[type]-rgb-[color]_[name].[ext]
```

- **type**: `elements`, `textures`, `icons`, `illustrations`
- **color**: `red`, `black`, `white`
- **ext**: `.ai` (vector, Adobe Illustrator), `.png` (raster, transparent background), `.svg` (vector, icons only)

Logos use a different pattern:
```
uw-[logo-type]-[color-variant]-web-digital.[ext]
```
