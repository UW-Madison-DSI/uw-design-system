# UW-Madison Brand Fonts

Red Hat Display and Red Hat Text, the official UW-Madison brand typefaces. Downloaded from the UW font CDN (`cdn.wisc.cloud`).

## Files

| File | Family | Style | Weight Range | Character Set |
|------|--------|-------|-------------|---------------|
| `redhat-display-latin.woff2` | Red Hat Display | Normal | 300-900 | Latin |
| `redhat-display-italic-latin.woff2` | Red Hat Display | Italic | 300-900 | Latin |
| `redhat-display-latin-ext.woff2` | Red Hat Display | Normal | 300-900 | Latin Extended |
| `redhat-display-italic-latin-ext.woff2` | Red Hat Display | Italic | 300-900 | Latin Extended |
| `redhat-text-latin.woff2` | Red Hat Text | Normal | 300-625 | Latin |
| `redhat-text-italic-latin.woff2` | Red Hat Text | Italic | 300-625 | Latin |
| `redhat-text-latin-ext.woff2` | Red Hat Text | Normal | 300-625 | Latin Extended |
| `redhat-text-italic-latin-ext.woff2` | Red Hat Text | Italic | 300-625 | Latin Extended |

## Usage

- **Red Hat Display**: Headings, headlines, large sizes. Weights used: 400, 500, 600, 700.
- **Red Hat Text**: Body copy, UI text, small sizes. Weights used: 400, 400i, 700.
- **Fallback**: Arial (system font).

See `tokens.md` for font family token definitions and `tokens.json` for the machine-readable format.
